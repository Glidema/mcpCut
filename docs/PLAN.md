## 以后可以做的切口（未开工）

仍然遵守：声明式时间线、少工具名、智能旁路、异步出片、本地文件、原片不动。

### 更会剪（仍让 Agent 拍板）

- **按切点拆段**：把 `scenes` 结果变成一组 `edit_timeline` 建议（例如「每段 ≥1.2s 的 18 刀变成 8 条可用镜头」），应用前必须 `describe` 确认。不要在引擎里自动重剪。
- **按节拍切 MV**：在视觉 `scene` 之外对音轨做 onset / 鼓点检测，旁路一份 `beats.json`。口播片不默认开。
- **静音/气口**：对口播做 silence 检测，旁路建议删掉的区间。和 Whisper 互补（有词用转写，没词用静音）。
- **SRT → 字幕轨**：可选 `applyCaptions`，把旁路 SRT 写成 `tracks.text`（仍要 Agent 调用，默认不写）。口播成片才会常用。
- **从 SRT/JSON 导入现成字幕**，不必每次 Whisper。

### 成片更完整

- **封面/海报帧**：指定时间线秒数出一张封面 JPEG（可复用 preview 抽帧）。
- **GIF / 静图序列**：短循环预览，给聊天里看动效而不出整段 mp4。
- **响度**：对白与 BGM 的简单 LUFS / 限幅，避免配乐盖过人声。
- **速度**：`add_video` 增加 `rate`（0.5 / 2x），仍声明式，不暴露 `setpts`。
- **模板**：钩子-正文-CTA 三段时长建议（例如 3s+12s+2s），只出描述和默认 trim，不锁死内容。

### 给 Agent 更好用

- **job 进度**：`get_job` 带粗粒度 percent / 阶段（抽音、转写、编码），减少盲目轮询。
- **工具仍要少**：新能力优先做成现有工具的可选字段。Cursor 缓存目录，新名字就要 Reload + 新对话。
- **工程列表**：`list_projects` 或 MCP resource 扫 `.mcpcut/projects`，避免 Agent 忘掉 `projectId`。
- **安全区**：字幕默认避开 9:16 底部系统栏；`position` 再增加 `safe-bottom`。
